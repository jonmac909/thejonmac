Static personal site for Jon Mac, recovered from the Wayback Machine (Dec 17, 2025 snapshot) after the original GoHighLevel-hosted site went down.

- `_redirects` — Cloudflare Pages redirects (`/rates` → Notion partners page)

Hosted on Cloudflare Pages.
